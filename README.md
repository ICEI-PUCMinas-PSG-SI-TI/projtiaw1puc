# PROJETOSIGNALS
Projeto de software da disciplina TIAW da PUC Minas sobre a exclusão de pessoas surdas em eventos culturais. A finalidade da aplicação web é auxiliar e conectar nesses contextos pessoas surdas, seja por localização, guia de espaços, notícias, intérpretes, informações de acessibilidade; profissionais como os intérpretes, organizadores de eventos e empresas que desejam contratar esses serviços, para assim proporcionar eventos inclusivos.

# FUNCIONALIDADES
Na página principal, temos os acessos para todas as seções, sendo essas: Serviços, Trabalhe Conosco, Mapas, Eventos. As notícias e os eventos atuais estão na página principal para facilitar a busca. Barra de pesquisa, botão de voltar à página principal em cada página consultada, botão de filtro, menu principal para ajuda ao usuário, conta. 
# REQUISITOS PARA INSTALAÇÃO E USO

Nosso projeto é desenvolvido com tecnologias front-end. É necessário ter o Git na máquina local e o Github, IDE Visual Studio Code, Node.js e ES6 code snippets para JavaScript, extensões como o Live Server para visualização no navegador.
